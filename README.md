# תמלול פלוס – מערכת תמלול הקלטות

אתר (וגם אפליקציה להתקנה בטלפון) שמתמלל הקלטות קוליות לטקסט: **עברית, יידיש ואנגלית**.

🔗 כתובת: https://328516885.github.io/tamlul-plus/

## מה יש במערכת
- כניסה עם שם משתמש וסיסמה. אם שכחת את הסיסמה, נשלח למייל קוד בן 4 ספרות ואיתו קובעים סיסמה חדשה.
- הקלטה ישירה מהמיקרופון, או העלאה של כמה קבצים ביחד (הודעות קוליות מוואטסאפ, mp3, m4a, wav ועוד). כל הקבצים נכנסים לתור ומתמללים אחד אחרי השני.
- תמלול עם Whisper Large v3 דרך Groq (חינם). קבצים ארוכים מחולקים אוטומטית לחלקים.
- ✨ סיכום אוטומטי בעברית (Groq, והמודל נבחר אוטומטית מתוך המודלים הזמינים).
- ספרייה: תיקיות, תגיות, חיפוש בתוך התמלולים, נגן עם גל קול, ולחיצה על משפט מנגנת אותו.
- ייצוא ל-Excel, Word, PDF ו-TXT מימין לשמאל, וגם Excel של כל הספרייה.
- מצב חושך 🌙, מסך סטטיסטיקה, גיבוי ושחזור.
- התקנה כאפליקציה (PWA). באנדרואיד אפשר לשתף הקלטה מוואטסאפ ישירות לאפליקציה.

## הגדרה ראשונה
1. פותחים את האתר ויוצרים משתמש מנהל: שם משתמש, מייל וסיסמה.
2. מקבלים מפתח חינמי ב-https://console.groq.com/keys.
3. בהגדרות, תחת Groq, מדביקים את המפתח ולוחצים "שמירה".

## פרטיות
כל ההקלטות והתמלולים נשמרים **רק במכשיר שלך** (IndexedDB בדפדפן). השמע נשלח ל-Groq רק לצורך התמלול, ומפתח ה-API נשמר רק במכשיר.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה (עיצוב וקוד) |
| `sw.js` | Service Worker: עבודה בלי אינטרנט, התקנה וקבלת שיתוף מוואטסאפ |
| `manifest.webmanifest` | הגדרות האפליקציה להתקנה |
| `icon-*.png`, `apple-touch-icon.png` | אייקונים |

## שירותים חיצוניים
- **Groq**: תמלול (`whisper-large-v3`) וסיכום.
- **EmailJS**: שליחת קוד שחזור הסיסמה (שירות `service_nybca58`, תבנית `template_9e88gji`, עם השדות `{{to_email}}` ו-`{{message}}`).
- ספריות הייצוא נטענות רק כשמשתמשים בהן: SheetJS, docx ו-html2pdf.js.
